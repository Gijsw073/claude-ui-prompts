# Example: Next.js App

A minimal Next.js 14 app showing several prompts from this library in action.

## What's included

- Hero section (from [sections/landing-page/hero.md](../../sections/landing-page/hero.md))
- Features grid (from [sections/landing-page/features.md](../../sections/landing-page/features.md))
- Navbar (from [sections/navigation/navbar.md](../../sections/navigation/navbar.md))
- SEO metadata (from [sections/seo-geo/meta-tags.md](../../sections/seo-geo/meta-tags.md))

## Running locally

```bash
npx create-next-app@latest my-app --typescript --tailwind --app
cd my-app
# Copy app/page.tsx from this directory into your project
npm run dev
```

## How the prompts were used

Each section in `app/page.tsx` was generated by copying the prompt from the relevant markdown file and pasting it directly into Claude. No manual editing needed — the output was clean on the first try.

This is the point of `claude-ui-prompts`: the first draft ships.
